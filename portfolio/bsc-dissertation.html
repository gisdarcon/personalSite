Project Description

My B.Sc. dissertation at the Department of Topography, TEI of Athens developed a desktop GIS application for the dynamic management of Urban Decrees (planning permissions and building regulations) in the Municipality of Aigaleo, Athens.

The application was built using ArcView GIS 3.x and the Avenue scripting language, with a Visual Basic interface for data entry and report generation. Key features included:

  • Spatial database of all urban decree boundaries and associated planning constraints
  • Attribute-linked queries enabling planners to retrieve relevant legislation for any parcel
  • Automated report generation for planning permission enquiries
  • Integration with cadastral map data
  • DDE communication between software and the digitisation of historical planning maps.

The project demonstrated the potential of desktop GIS for administrative workflows in Greek local government, at a time when spatial data management in municipalities was largely paper-based.
